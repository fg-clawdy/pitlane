## Codebase Patterns
- Use Fastify 5.x as the web framework (not Express)
- Prisma ORM for database operations with PostgreSQL
- JWT tokens use RS256 asymmetric encryption
- API endpoints follow REST conventions with /api/v1 prefix
- All modules are in apps/api/src/modules/ directory
- Environment variables managed via .env files
- Project uses npm workspaces with apps/* structure
- TypeScript compilation: npx tsc --project apps/api/tsconfig.json
- Data discrepancy tracking: compare Jolpica values with admin-protected values field by field
- Commissioner notifications use Notification model with type 'data_discrepancy'
- Scoring module supports all three scoring types: fia_official, linear_20, proprietary
- DGE (Double Goose Egg) tracking is built into the scoring calculation and persisted to RaceScore
- Draft pick WebSocket broadcasting via DraftsService.registerWebSocketClient/unregisterWebSocketClient
